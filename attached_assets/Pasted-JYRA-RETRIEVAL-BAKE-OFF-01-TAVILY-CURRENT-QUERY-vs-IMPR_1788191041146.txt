JYRA — RETRIEVAL BAKE-OFF 01
TAVILY CURRENT QUERY vs IMPROVED GENERIC QUERY vs EXA
ON THE EXACT 7 RETRIEVAL FAILURES

PURPOSE

MVP Fix Cycle 02 established:

Frozen controls = 10
Detected events = 2
Missed events = 8

Miss attribution:
- 7 retrieval / query-result relevance failures
- 1 evidence/fact-extraction failure
- 2 successful controls

Therefore the dominant current bottleneck appears to be RETRIEVAL.

Before changing JYRA's production research architecture, determine:

1. Are the current JYRA research queries inadequate?
2. Can better generic query construction materially improve Tavily recall?
3. Does Exa retrieve materially better event evidence than Tavily?
4. Or are the target events difficult for BOTH providers to retrieve?

THIS IS A CONTROLLED PROVIDER/QUERY EXPLORATION.

DO NOT integrate Exa into WEB_SEARCH.
DO NOT modify production intelligence behavior.

==================================================

the original miss.

ARM C — EXA IMPROVED GENERIC QUERY

Use the SAME generic research objective/query semantics as Arm B as
closely as provider syntax allows.

Do not optimize the Exa query using knowledge of the reference event.

10. REFERENCE EVENT EVALUATION
==================================================

AFTER all retrieval for a company is complete, use the frozen reference
manifest to adjudicate results.

For every result classify:

EXACT_EVENT

SAME_EVENT_ALTERNATE_SOURCE

RELATED_EVENT

GENERIC_COMPANY_CONTENT

WRONG_ENTITY

IRRELEVANT

EXACT_EVENT means the retrieved evidence directly represents the known
reference event.

SAME_EVENT_ALTERNATE_SOURCE means another trustworthy source reports
the same event.

RELATED_EVENT does NOT count as successful known-event retrieval.

==================================================
11. EVENT FOUND DEFINITION
==================================================

An arm counts as EVENT_FOUND only when at least one returned result is:

EXACT_EVENT

or

SAME_EVENT_ALTERNATE_SOURCE

and contains enough information to support the relevant atomic fact.

A generic page about cybersecurity does not count.

A company homepage does not count.

A seller/service page does not count merely because it contains security
terminology.

==================================================
