==================================================
C. FIX UNKNOWN ≠ DORMANT
==================================================

Current behavior:

Score 0
DORMANT
Confidence Unknown
NEEDS MORE RESEARCH

is semantically misleading.

JYRA must distinguish:

"No opportunity evidence exists"

from:

"We do not have enough information to determine whether an opportunity
exists."

Missing evidence must NOT automatically become negative evidence.

UNKNOWN ≠ 0.

UNKNOWN ≠ DORMANT.

If Fit/Need/Timing cannot be evaluated because required information is
missing, represent the assessment as something such as:

NEEDS RESEARCH

or

INSUFFICIENT EVIDENCE

rather than DORMANT.

Use the existing domain model where possible rather than introducing
unnecessary new states.

==================================================
D. DORMANT SEMANTICS
==================================================

DORMANT should mean JYRA has sufficient information to reasonably
conclude that there is currently weak/no actionable opportunity.

Example:

Fit may be acceptable,
but there are no meaningful Need/Timing signals,
and evidence coverage is sufficient to support that conclusion.

It should NOT mean:

"We haven't researched this company."

==================================================
E. NULL VS ZERO
==================================================

Audit scoring implementation.

Unknown dimensions must not silently become numeric zero.

For example:

Fit = unknown
Need = unknown
Timing = unknown
Relationship = unknown

must not automatically calculate:

0 + 0 + 0 + 0 = opportunity score 0

unless the scoring model explicitly has sufficient evidence to assign
those zero values.

Preserve distinction between:

0 = evaluated and genuinely zero/very weak

NULL/UNKNOWN = not sufficiently evaluated.
